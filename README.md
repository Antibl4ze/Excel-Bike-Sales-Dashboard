# Excel Bike Sales Dashboard

An interactive Excel dashboard built from survey data on bike buyers, showing who buys bikes and what affects the purchase.

## What I did
- Cleaned the raw data: removed duplicates and standardised formats
- Analysed purchases and buyer demographics with pivot tables and SUMIFS
- Built charts and combined them into one dashboard
- Added slicers and conditional formatting so the dashboard can be filtered

## How to open
Download `Data scraping with excel.xlsx` (choose "View raw" / download) and open it in Excel.

## Tools
Excel (pivot tables, SUMIFS, charts, slicers, conditional formatting)
